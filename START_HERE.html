Back Then Stories CMS V2

Đây là CMS thật. Muốn chạy, máy cần PHP 8.2+ và Composer.
1. Cài Laravel Herd hoặc PHP + Composer.
2. Double-click SETUP_LOCAL_WINDOWS.bat.
3. Tạo tài khoản admin khi cửa sổ yêu cầu.
4. Double-click RUN_LOCAL_WINDOWS.bat.
5. Trình duyệt mở http://127.0.0.1:8000/admin.

Xem README-START-HERE.md để biết thêm.
